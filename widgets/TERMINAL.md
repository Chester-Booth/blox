# Terminal commands

Use `terminal` for TUIs and commands that need a PTY. For completed plain stdout, use [command output](COMMAND.md).

Terminal commands are trusted user configuration. The widget broker executes an argv array with no implicit shell. Complete settings require `command`, `workingDirectory`, `environment`, `columns`, `rows`, `maxRuntimeSeconds` and `restartPolicy`. `workingDirectory` is an absolute directory or an empty string for the broker's inherited directory. `environment` adds or replaces environment variables. `columns` and `rows` set the initial PTY size. No preset aliases or old command formats exist in this runtime. Saved settings missing any required field fail validation. Only new drafts receive catalogue defaults.

The shared broker owns each consumer's PTY, process group and generation. A small Python child performs Linux parent-death and controlling-terminal setup and immediately replaces itself with the command using `exec`. It leaves no Python daemon per widget. This avoids running Python setup between fork and exec in the broker. Unsubscribe, shutdown and an explicit runtime cap kill the command's process group and reap its direct child. Closing the controlling PTY sends the normal terminal hangup signal. Linux also kills the direct child if its parent dies. A trusted command can deliberately escape its process group or ignore terminal hangup, so this mechanism is not a sandbox for hostile executables.

`restartPolicy` is exactly `never` or `always`. New drafts use `never`. With `never`, direct-child exit plus PTY EOF retains the final grid and exit code indefinitely, including empty output and failed exits. A finite tree command stays a single invocation. With `always`, both clean and failed exits trigger recovery after EOF, descriptor detachment, process-group cleanup and direct-child reaping. An exited child whose descendant holds the PTY stays `draining`. Silence does not end it.

Recovery waits 500 ms after the first short attempt. Successive attempts lasting less than 30 seconds double that delay up to 30 seconds. An attempt lasting at least 30 seconds resets the delay to 500 ms. Duration ends at observed direct-child exit, so a long PTY drain does not reset backoff. Launch failures use the same policy. Parser and selector failures become `unavailable` and require manual recovery. Each wait has one scheduled deadline. Hide, unsubscribe, replacement and shutdown cancel it.

During backoff the broker retains the final grid and last exit or launch failure. A new attempt clears the screen, parser, decoder, byte counter and readiness, and immediately replaces old content with an empty partial grid. Its first bytes remain partial. Exit plus EOF settles it, even if it produced no bytes. The host generation stays unchanged during automatic recovery. Every frame also carries an `attempt` number. Envelope revisions continue increasing across attempts. Resize actions update the dimensions used by the next attempt, including during backoff. Exited and backoff processes receive no input.

`maxRuntimeSeconds` defaults to zero, which gives the subscription the consumer's visible lifetime. An explicit positive value up to 86400 seconds caps the whole subscription, including every attempt and restart wait. Expiry cancels recovery, kills the active group and retains the last grid with `stopReason: "runtime-limit"`. It cannot start an endless restart loop. Fresh reveal or `WidgetHost.refresh()` creates a new generation and budget. A permanently retained `never` result cancels its unused cap deadline. Broker transport recovery is separate and creates fresh work rather than preserving a finite process across broker death.

Terminal frame metadata includes `restartPolicy`, `attempt`, `lifecycle`, `restartPending`, `restartAtMonotonicMs`, and, during backoff, `restartDelaySeconds`. Lifecycle is `running`, `draining`, `retained-success`, `retained-failure`, `backoff`, `runtime-limit` or `unavailable`. Exit code, stop reason, readiness and byte count remain separate fields. These fields do not contain argv or cell text. The grid remains in `rows` and `changedRuns`. This change adds no visible status controls or application restart IPC.

Output volume does not stop a healthy visible command. The active grid retains at most 12000 cells, with at most 240 columns and 100 rows. An alternate screen may retain one additional grid with the same bound. The existing broker selector admits PTY work on readability. It unregisters the master during a fixed holdoff, uses a fixed 8 ms holdoff for the first burst, then publishes on anchored 16 ms slots while output is active. Silent, hidden and permanently retained terminals have no PTY polling timer. Runtime caps and restart waits have explicit deadlines. Direct-child exit uses a pidfd, with one shared SIGCHLD wakeup pipe on runtimes without pidfd support. EOF and child exit remain separate events.

Runnable terminals share a cooperative 2 ms parsing slice per broker turn and rotate after each 512-byte batch. Each admission reads at most 65536 bytes. Ingestion retains parser state without constructing snapshots. The broker constructs at most one snapshot per turn before returning to protocol I/O. A single parser operation, snapshot construction or JSON encoding can exceed the slice. These bounds do not guarantee 16 ms delivery under overload or stdout backpressure. Input writes are nonblocking, accept at most 4096 UTF-8 bytes, and return the number written. Backpressure may produce a short write.

The broker sends full keyframes and row patches bound to the last serialised frame. Blank cells and background colours remain explicit, including after an erase. The native decoder validates each message before staging a complete typed grid. Cell arrays stay in C++; QML receives bounded metadata and a frame token. Worker QPainter rendering compares complete retained grids, so coalesced observations cannot lose erasures. Generation, attempt, grid and appearance changes invalidate the relevant rendering state. Content uses font rendering, without HTML conversion or synthesised block glyphs. See [native transport and rendering](native/README.md) for the wire contract and bounds.

The parser supports incremental UTF-8, cursor movement, delayed wrapping, scroll regions, insert/delete/erase, basic alternate screen modes, ANSI colours, indexed colours, true colour, bold, underline and inverse. OSC/DCS strings are consumed without external actions. It does not implement a full terminal emulator. Unsupported controls, device replies, mouse modes, DEC graphics character sets and terminal queries have no effect. The cursor is not painted.

Combining codepoints attach to the preceding cell, up to eight codepoints per cell. East Asian wide/fullwidth characters reserve two cells. Width uses Python's Unicode database and can differ from the font. Extended grapheme clusters, emoji ZWJ sequences, variation selectors, bidirectional shaping, ambiguous-width configuration and combining sequences spanning a wrapped line are not fully supported. Fixed cell clipping prevents glyphs from painting unrelated cells, but cannot guarantee correct layout for those cases.

A live snapshot declares `readiness: "partial"` and `sourceCapabilities.completeLiveFrames: false`. Observing its first bytes proves only that this generation produced output. Arbitrary terminal output has no reliable full-frame boundary. Only process exit plus PTY EOF declares `settled`, and that describes the final captured output. Silence never proves a TUI has finished drawing. Production reveal decisions must retain this limitation rather than treating a ready QML item as proof of a complete live screen.

Fullscreen supports `fit`, `scroll` and `resize`. Fit scales the retained grid. Scroll retains its dimensions and permits panning. Resize emits a broker action derived from the actual viewport and measured font cells, bounded by the same grid limits. The host supplies `context.fullscreenMode` and routes `actionRequested("resize", {columns, rows})` to the current consumer. Leaving resize mode restores the configured normal grid. All fullscreen modes hide scrollbars.

Run the offscreen paint, blank clearing and fullscreen geometry fixture with `python widgets/tests/render_terminal.py --output-directory /tmp/blox-terminal-render`.
